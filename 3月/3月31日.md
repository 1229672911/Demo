- **$GOPATH$的设置有什么意义**

  - $GOPATH$可以看作GO语言的工作目录，他的值是一个目录的路径，也可以是多个目录的路径，每个目录都代表$GO$语言的一个工作区。这个工作区可以防止$GO$语言的源码文件以及安装后的归档文件和可执行文件。                            

  - 其实在之前$GOPATH$时代必须不能放$go.mod$文件，且执行文件必须放在$GOPATH$目录下。

  - 而在之后$Module$模式之后可以任意放置位置，但是必须使用$go.mod$文件，且$go.mod$文件必须明确记录依赖版本。

- **$MapStructure:$**结构体映射的字段名，就是映射到$JSON$中的字段名称，前面字段的名称是在程序中用到的变量名称。

- $gorm:"-"$会**完全禁用所有数据库交互**，包括存储，查询，关联查询。

- 在$GORM$中，$query$就像乐高积木，可以不断拼接但不会立即执行，延迟执行的时候只是在**构建查询条件**

- 只有遇到$Find/First/Count$等方法时才会真正查询数据库。

- **$where$的几种模糊查询**

```go
// 查询名字包含"张"的所有用户
db.Where("name LIKE ?", "%张%").Find(&users)
```

- `%张` → 以"张"结尾
- 张%` → 以"张"开头` 
- %张%` → 包含"张"

```go
// 查询名字第二个字是"三"的用户
db.Where("name LIKE ?", "_三%").Find(&users)
```

- `-`代表单个任意字符

```go
// 查询符合手机号格式的记录
db.Where("phone REGEXP ?", "^1[3-9]\\d{9}$").Find(&users)//匹配所有中国大陆手机号
```

正则表达式写法，支持正则语法

- `^` 开头
- `$` 结尾
- `[0-9]` 数字范围
- `{n}` 重复次数

```go
db.Where("name LIKE ? AND age > ?", "%张%", 18).Find(&users)
//或
db.Where("name LIKE ?", "%张%").
   Where("age > ?", 18).
   Find(&users)
```

- 使用$LIKE$的链式调用

```go
// 使用LOWER函数（适合不区分大小写的数据库）
db.Where("LOWER(name) LIKE LOWER(?)", "%john%")
```

- 大小写模糊查询

## 登录日志

**日志列表中的字段：**

- 日志编号：自增$ID$
- 用户名称：记录登录用户的名称
- 登录状态：成功，失败
- $IP$地址：登录请求的$IP$地址
- 访问日期：时间格式，$yyyy$年$MM$月$dd$日 $HH:mm:ss$

并且可以在操作中查看详细信息

详细信息包括：操作类型，系统模块，请求方式，操作状态，请求地址，操作方法，请求参数，返回结果，$IP$地址，操作人，操作日期。

设计表结构，数据库创建表，实现查看的接口。实现根据登录信息自动创建日志。

### 表结构

- 日志编号：自增$ID$。使用$autoIncerment$字段创建，并设置为主键，$primatyKey$

- 用户名称：记录登录用户的名称。用string储存。

- 登录状态：成功，失败。用string实现，但是只返回成功或者失败。或者可以用$bool$来实现并且根据$bool$值来返回登录状态。

- $IP$地址：登录请求的$IP$地址。用$string$来储存

- 访问日期：时间格式，$yyyy$年$MM$月$dd$日 $HH:mm:ss$。可以用$string$来储存，字符串可以储存任何格式的时间。或者用$datetime$类型，同时用$format$来自定义时间格式化。只需后面给上一个示例就可以。
  ```go
  OpTime time.Time `format:"2006-01-02"` 
  // 把时间显示为YYYY-MM-DD格式
  ```



### 建表

```go
type SysLoginLog struct {
	gorm.Model
	LoginLogId  int       `gorm:"type:int64;autoIncrement" mapstructure:"login_log_id"`                           //日志编号，登录日志ID，自增类型
	UserName    string    `gorm:"type:varchar(255);not null" mapstructure:"user_name"`                            //登录的用户名
	LoginStatus string    `gorm:"type:varchar(255);not null" mapstructure:"login_status"`                         //登录状态，成功或失败
	IpAddress   string    `gorm:"type:varchar(255);not null" mapstructure:"ip_address"`                           //IP地址
	LoginTime   time.Time `gorm:"type:datetime;not null"  mapstructure:"login_time" format:"2025-01-23 15:04:05"` //访问日期
}
```



### 登录日志接口

**要实现的功能有：**

- 能分页查看日志列表的大概信息。并在此实现关键词的搜索。

- 能查看到详细信息
  - 可以根据关键字查询到相关日志记录，关键字有：日志编号，用户名称，主机（$IP$地址？），系统模块，操作类型，请求方式。
- 能根据登录的用户的信息自动创建日志记录
- 之后还要实现根据计时器去删除数据 
  - 每天遍历所有数据的时间戳，删除所有过期的数据。
