## 路由引擎

配置了路由引擎之后，当有对应的“/xx”请求才会被响应，而配置了默认路由后就可以将所有没有写的“/yy”类的相应统一转到一个页面

“/xx”类的引擎需要实现

配置了路由引擎后，应用程序会根据 HTTP 请求的路径（如 `/home`、`/login`）和方法（如 `GET`、`POST`）来调用对应的处理函数或控制器。



## $gin.Context$

1. **表示指针：**

   $gin.Context$是一个指针类型，指向 $gin.Context$ 结构体。指针是对结构体的引用，避免在函数调用时复制整个结构体，从而提高性能。

2. **$gin.Context $结构体:**

   这是 $Gin$ 框架中的一个核心结构体，封装了当前 $HTTP$ 请求和响应的所有信息。

   它提供了许多方法来获取请求数据、设置响应数据以及控制请求的生命周期。

3. **$HTTP$ 请求上下文的容器：**

   $*gin.Context$ 是 $Gin$ 框架处理请求的核心对象。$Gin $框架会将每个 $HTTP $请求封装为一个 `*gin.Context` 对象，并传递给路由处理函数。



## go的模板

**定义模板** 

比如按照  $\text{html}$  语法写一个$tmpl$文件，之后在解析模板里用路径找到再去解析

**解析模板**

上面定义好了模板文件之后，可以使用下面的常用方法去解析模板文件，得到模板对象：

```go
func (t *Template) Parse(src string) (*Template, error)//无需从文件加载模板，可以直接用string定义模板

func ParseFiles(filenames ...string) (*Template, error)//string可以写文件的路径，当需要从文件中加载模板使用

func ParseGlob(pattern string) (*Template, error)//需要批量加载匹配某个文件使用
```

结构体也可以作为模板

也可以使用`func New(name string) *Template`函数创建一个名为`name`的模板，然后对其调用上面的方法去解析模板字符串或模板文件。



**渲染模板**

渲染模板简单来说就是使用数据去填充模板，当然实际上可能会复杂很多。

```go
func (t *Template) Execute(wr io.Writer, data interface{}) error//使得程序中的string可以替换模板中{{ . }}的内容

```

## $Go$的反射

Go语言中的变量是分为两部分的:

1-类型信息：预先定义好的元信息。

2-值信息：程序运行过程中可动态变化的。

反射是指在程序运行期间对程序本身进行访问和修改的能力。程序在编译时，变量被转换为内存地址，变量名不会被编译器写入到可执行部分。在运行程序时，程序无法获取自身的信息。

支持反射的语言可以在程序编译期间将变量的反射信息，如字段名称、类型信息、结构体信息等整合到可执行文件中，并给程序提供接口访问反射信息，这样就可以在程序运行期间获取类型的反射信息，并且有能力修改它们。

Go程序在运行期间使用reflect包访问程序的反射信息。
